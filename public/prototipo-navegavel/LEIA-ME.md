# Protótipo navegável

Abra `http://localhost:3000/prototipo-navegavel/index.html` com o servidor de desenvolvimento do front ativo.

O protótipo é HTML/CSS/JavaScript estático. Os dados são fictícios, os botões apenas exibem mensagens demonstrativas e nenhuma chamada é feita à API. Use o menu lateral para visitar as áreas e telas principais do produto; alguns fluxos internos também podem ser abertos clicando nas linhas.
